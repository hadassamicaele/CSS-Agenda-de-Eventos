🌷 Sobre o projeto

Este repositório reúne um projeto de agenda de eventos, desenvolvido com o objetivo de praticar e aprimorar conhecimentos em desenvolvimento web.

A proposta é criar uma página organizada, visualmente agradável e de fácil navegação, aplicando conceitos de estruturação e estilização.
